# Knowledge Context Capability Resolution V1

Knowledge-specific minimum context window = `NOT_DEFINED`.

Knowledge general remains supported at Core 4096, subject to the existing
shared retrieval cap and reservations. Core 4096 does not guarantee complete
admission of three simultaneous document evidences. The preserved historical
result is `ADMISSION_BUDGET_INFEASIBLE_UNDER_4K`; it is evidence, not a PASS.

The supplemental Core 8192 profile is
`SUPPLEMENTAL_OPERATIONAL_PROFILE_8K`, with result
`SUPPLEMENTAL 8K MULTI-SOURCE PROFILE PASS`. Under the evaluated contracts it
demonstrates complete comparison of up to three evidences. It does not define
a universal mathematical minimum or arbitrary capacity for N sources.

This resolution does not change `SharedRetrievalCap`, reservations, framing,
citations, provenance, corpus, gold, scorer, thresholds, or historical
manifests. The 4K and 8K results remain distinct and the K8 post-cert state
remains `K8 POST-CERT REMEDIATION PARTIAL`.
